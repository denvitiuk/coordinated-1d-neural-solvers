# Отчёт: метод координации в экологической задаче (загрязнение воздуха)

Дата: 2026-11-10. CPU, float64. Повторить: `python eco_pollution.py`,
`python eco_benchmark.py`; проверки: `python checks/run_checks.py` (все проходят).

## 1. Постановка

Стационарное распространение примеси над районом 20 × 10 км:

    -∇·(K ∇c) + w·∇c + λ c = S,   c = 0 на границе (фон вычтен).

| Величина | Что задано |
|---|---|
| K(x, y) — турбулентная диффузия | 1.5 км²/ч, над городом до 5.5 (шероховатость застройки) |
| w(x, y) — ветер | западный 4.8–8 км/ч со сдвигом по высоте, плюс меандр ±1.5 км/ч |
| λ(x, y) — выведение | 0.05 1/ч, над лесом +0.6 1/ч (осаждение) |
| S — источники | ТЭЦ (точечный), промзона (пятно), автобан (линейный, по диагонали) |

Модель демонстрационная: порядок величин правдоподобный, но параметры
не откалиброваны по реальным измерениям, единицы концентрации условные.

**Почему эта задача важна для метода.** Все коэффициенты переменные, а
адвекция делает оператор несимметричным. Поэтому быстрые точные методы
для пластины (разложение по собственным векторам, БПФ) здесь неприменимы.
Метод координации работает без изменений:

    Lx u = -q + S/2   (прогонки вдоль x),   Ly v = q + S/2   (прогонки вдоль y),
    J(q) = ½‖u - v‖² -> 0,  тогда c = u = v и (Lx + Ly) c = S.

Схема: консервативная диффузия и адвекция против потока. Она монотонна:
концентрация не бывает отрицательной и не осциллирует.

## 2. Результаты

**Точность** (сетка 41 × 21, сравнение с прямым решением всей двумерной
системы): относительная ошибка 2e−15, то есть до машинной точности.

**Скорость** (rtol 1e−10, время включает подготовку):

| Сетка | Неизвестных | GMRES + ADI | GMRES без ADI | Прямое (плотная LU) |
|---|---|---|---|---|
| 101×51 | 4 851 | **6 it, 0.08 с** | 360 it, 0.77 с | 0.38 с |
| 201×101 | 19 701 | **8 it, 0.22 с** | 457 it, 1.98 с | не помещается разумно |
| 401×201 | 79 401 | **9 it, 1.1 с** | 591 it, 5.7 с | — |
| 801×401 | 318 801 | **10 it, 1.7 с** | — | — |

Число итераций с ADI почти не растёт (6 → 10 при увеличении задачи в 66 раз),
как и на пластине. Значит, ADI-предобусловливание остаётся эффективным и
при переменных коэффициентах и ветре, хотя теория гарантирует это только
для постоянных.

**Что модель даёт эколог-аналитику** (сетка 201 × 101):

| Вопрос | Ответ | Цена |
|---|---|---|
| Поле концентрации | максимум 9.8 у ТЭЦ, зона c > 1 — 116 км² из 200 | 8 итераций, 0.18 с |
| Вклад каждого источника | в точке «Больница»: ТЭЦ 1.97, автобан 0.57, промзона 0.46 | по 0.18 с на источник; сумма вкладов = полное поле (2e−10) |
| Сценарий «фильтр на ТЭЦ −50 %» | «Больница» 2.99 → 2.01, зона c > 1: 116 → 100 км² | без нового расчёта, по линейности |
| Откуда приходит загрязнение в точку | карта влияния φ (`eco_influence_*.png`) | одна сопряжённая задача, 7 итераций |

Карта влияния — это та же сопряжённая задача, что и в градиенте из диплома
(Aᵀp = r), только для всего двумерного оператора. Одно решение показывает,
выброс из какого места сильнее всего влияет на больницу, школу или
измерительную станцию. Проверено: c(рецептор) = ⟨φ, S⟩ совпадает с прямым
расчётом до 1e−9.

Картинки: `results/eco_concentration_201x101.png` (√c, чтобы был виден
не только пик) и `results/eco_influence_201x101.png`.

## 3. Найденная по ходу оптимизация

При переменных коэффициентах у каждой строки своя трёхдиагональная матрица.
Быстрый путь через BLAS (из оптимизации пластины) тогда хранит batch·n²
чисел и проигрывает обычной прогонке в 20 раз (9.5 с против 0.44 с на
401 × 201). Автоматический выбор исправлен: BLAS-путь берётся только для
одной общей матрицы. Для пластины всё осталось как было.

## 4. Имеет ли смысл

- **Да.** Это первая задача, где у метода нет простого конкурента:
  прямые «быстрые» методы не применимы, плотная LU не помещается уже
  на 200 × 100. Координация решает 320 тысяч неизвестных за 1.7 с на ноутбуке.
- Честный конкурент — разреженный прямой решатель (SuperLU, PARDISO) или
  многосеточный метод. В окружении проекта их нет (нет scipy), поэтому
  сравнения с ними здесь нет. На двумерных задачах такого размера они,
  скорее всего, сопоставимы по скорости. Преимущество координации — в
  структуре: только независимые одномерные задачи, что удобно для GPU,
  распределённого счёта и разбиения по регионам.
- Модель стационарная и двумерная. Для реальной практики (например,
  оценка выбросов по TA Luft / BImSchG) нужны: зависимость от времени
  (тот же метод на каждом шаге по времени), реальные метеоданные,
  вертикальное измерение (3D — третье семейство прогонок) и калибровка
  по станциям Umweltbundesamt.

## 5. Обратная задача: источники по измерениям станций

Скрипт `eco_inverse.py`. Модель линейна, поэтому показание станции m равно
d_m = ⟨φ_m, S⟩, где Lᵀφ_m = e_m («след» станции). На каждую станцию решается
одна сопряжённая задача тем же методом координации (6–7 итераций).
24 станции считаются за 3.8 с. После этого вклад источника в любой точке
получается без новых решений, и перебор всех 19 701 мест занимает 80 мс.

**Сценарий (синтетический).** ТЭЦ заявляет 100, а выбрасывает 130.
Кроме того, есть незаявленный пожар мощностью 50 в точке (11, 8) км.
«Истина» считается на сетке 401 × 201, восстановление идёт на 201 × 101,
шум измерений 5 % + 0.02. В веса МНК добавлена ошибка модели 3 %.

**Что получилось (12 станций):**
- Заявленные мощности данным не соответствуют: χ²/M = 20.7, то есть нарушение видно сразу.
- Если искать только мощности известных источников, ТЭЦ получается 158 ± 7.
  Оценка завышена: в неё попадает и пожар.
- С поиском пожара (медианы по 50 наборам шума) ТЭЦ = 123 [111–132]
  при истине 130. Пожар = 49 при истине 50, но квартили широкие: 40–250.
  Ошибка места: медиана 1.6 км, в 30 % случаев меньше 1 км, в 32 % больше 3 км.
- 95 %-я область накрывает истинное место в 100 % наборов шума,
  то есть оценка неопределённости честная.

**Сколько нужно станций** (50 случайных сетей с разным шумом на каждое число):

| станций | ошибка места (медиана) | < 1 км | ошибка мощности пожара | истина в 95 % |
|---:|---:|---:|---:|---:|
| 4 | 5.8 км | 6 % | 104 % | 52 % |
| 6 | 2.3 км | 12 % | 61 % | 82 % |
| 8 | 1.7 км | 32 % | 44 % | 92 % |
| 12 | 1.0 км | 44 % | 25 % | 92 % |
| 16 | 1.0 км | 50 % | 14 % | 98 % |
| 24 | 0.5 км | 86 % | 11 % | 92 % |

При 4 станциях неизвестных (6) больше, чем данных, и задача не решается.
Мощность ТЭЦ определяется уже с 8 станций. Место пожара хорошо определяется
только от 16–24 станций: одна станция видит, что облако пришло с запада,
но не видит, с какого расстояния. Поэтому вероятная область вытянута
полосой против ветра (`results/eco_inverse_location.png`).

**Ограничения, введённые в перебор:**
- мощности не могут быть отрицательными (кандидат отбрасывается);
- кандидаты ближе 1 км к известным точечным источникам не рассматриваются:
  добавка в той же точке неотличима от изменения мощности самого источника.

**Ошибка модели.** Грубая сетка отличается от мелкой меньше чем на 1 % почти
на всех станциях. Исключение — две станции у ТЭЦ: 4 % и 36 % (наветренная сторона,
где концентрация мала). Это численная диффузия схемы против потока
первого порядка: ошибка уменьшается вдвое при каждом измельчении сетки.

**Для реальной задачи** (станции Umweltbundesamt, ветер DWD) нужно:
нестационарная модель (ветер меняется по часам, и это сильно улучшает
определение места: полосы от разных направлений пересекаются),
реальный фон и вертикальное измерение.
